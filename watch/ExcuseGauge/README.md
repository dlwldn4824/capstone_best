# ExcuseGauge — watchOS 데모

아침에 손목에서 30초 안에 끝나는 화면. 발표 시연용이다.

```
어젯밤 얼마나 달랐나        게이지
센서가 본 것               한 줄
어제 이런 일 있었나요?      탭 4개
판정                       그럴 만해요 / 남았어요 / 사흘째
설명 안 된 밤              이레치 막대
```

## 시연 방법

**날짜를 탭하면 시나리오가 바뀐다.** 세 개가 순환한다.

| 시나리오 | 무엇을 보여주나 |
| --- | --- |
| 운동한 날 | 센서가 스스로 46%를 설명한다. "운동했어요" 를 누르면 68%까지 채워지고 → **그럴 만해요** |
| 발표 있던 날 | 피부전도로 38% 설명. "긴장했어요" 를 누르면 62% → **그럴 만해요** |
| **짚이는 게 없는 날** | 센서도 사람도 설명 못 한다. 이미 이틀 쌓여 있어 → **사흘째 설명되지 않았어요** |

세 개를 차례로 보여주는 것이 주장 전체다 —
**설명되는 것은 걸러내고 남은 것만 알린다.**

## 실행

macOS + Xcode 15 이상이 필요하다.

1. Xcode → File → New → Project → **watchOS → App**
   - Product Name: `ExcuseGauge`
   - Interface: SwiftUI, Language: Swift
2. 생성된 프로젝트의 `ContentView.swift` 와 `ExcuseGaugeApp.swift` 를 지우고
   이 폴더의 네 파일을 드래그해 넣는다
3. 시뮬레이터(Apple Watch Series 9 / 45mm 권장)에서 Run

실기기에 올리려면 Apple Developer 계정(무료 계정도 7일 임시 서명 가능)이 필요하다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `Model.swift` | 원인·하룻밤·판정 로직. **화면과 분리되어 있다** |
| `GaugeView.swift` | 게이지 막대, 이레치 막대, 칩 |
| `ContentView.swift` | 화면 구성 |
| `ExcuseGaugeApp.swift` | 진입점 |

## 설계 메모

**남은 부분에 경고색을 쓰지 않는다.** 설명 안 된 것은 나쁜 것이 아니라
모르는 것이다. 사흘이 쌓였을 때만 색이 바뀐다.

**센서 근거와 사용자 답변을 같은 자료형으로 다룬다.** `Engine.evaluate` 가
둘 중 큰 쪽을 취한다. 더하지 않는 이유는 같은 원인을 두 번 세지 않기 위해서다.

**진단 문구를 쓰지 않는다.** 판정의 `footnote` 가 매번 그 점을 상기시킨다.

## ⚠ 검증되지 않음

이 코드는 **Windows 환경에서 작성되어 컴파일된 적이 없다.**
Xcode 에서 처음 열 때 사소한 오류가 날 수 있다. 특히
`FlowRow` 는 단순 세로 배치로 두었으므로 화면 크기에 따라 조정이 필요할 수 있다.
