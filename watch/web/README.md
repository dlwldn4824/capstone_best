# 어디서나 열리는 데모 사본

`index.html` 을 **더블클릭**하면 끝입니다. 설치할 것도, 인터넷도 필요 없습니다.
Windows / macOS / Linux 어느 브라우저에서나 열립니다.

발표장 노트북에 Xcode 가 없을 때 쓰라고 만든 것입니다.

## 왜 따로 만들었나

원본은 `../ExcuseGauge/` 의 SwiftUI watchOS 앱인데 **Mac 과 Xcode 가 있어야**
돕니다. 팀 노트북이 전부 Windows 라 아무도 열어본 적이 없었습니다.
발표 당일에 안 켜지면 거기서 끝나므로 사본을 만들었습니다.

## 무엇이 같고 무엇이 다른가

| | |
| --- | --- |
| **같다** | `Engine.evaluate()` 계산, 상한 처리, 경보 조건, 화면 문구, 색값 |
| **다르다** | 글꼴(SF 대신 IBM Plex), 스크롤 관성, 실제 센서 연결 없음 |

판정 코드는 `Model.swift` 를 한 줄씩 옮긴 것입니다. **원본을 고치면 여기도 고쳐야
합니다.** 두 벌이 갈라지면 데모가 거짓말을 하게 됩니다.

## 발표용으로 붙인 것

시계 화면은 프로젝터에서 안 보입니다. 그래서 옆에 **판정 과정 패널**을 뒀습니다.

- 원인별 `센서 / 내가 확인 / 채택 / 실제 반영` 이 실시간으로 바뀝니다
- 상한에 걸린 값은 `(상한)` 으로 표시됩니다
- 경보 두 조건(남은 비율 60% 이상, 직전 이틀 연속)의 통과 여부가 그대로 보입니다

칩을 누르면 표가 같이 움직이므로 **"왜 더하지 않고 큰 쪽을 고르나"** 를
말로 설명하지 않고 눌러서 보여줄 수 있습니다.

화면 오른쪽 아래 100 / 150 / 200% 로 키울 수 있습니다.

## 조작

| | |
| --- | --- |
| 날짜 탭 | 시나리오 전환 (운동한 날 → 발표 있던 날 → 짚이는 게 없는 날) |
| 칩 | 원인 확인 / 해제 |
| 크라운 끌기 | 화면 스크롤 |

## 시연 순서 (권장)

1. **운동한 날** — 센서가 이미 46 을 설명함. 게이지 절반이 차 있다
2. "운동했어요" 누름 → 68 로 늘고 **"그럴 만해요"**. 옆 표에서 `max(46, 68)` 확인
3. "술 마셨어요" 추가 → 82/82, **100% 설명됨**
4. 날짜 탭 두 번 → **짚이는 게 없는 날**. 아무것도 안 눌러도 100% 가 남고
   직전 이틀이 78, 83 이라 **경보가 울림**
5. 게이지 남은 부분이 회색에서 주황으로 바뀌는 것을 짚을 것 —
   **사흘이 쌓이기 전까지는 경고색을 쓰지 않는다**

## 주의

시나리오 세 개의 수치는 **화면 설명용 예시**입니다. 실제 검증 결과가 아닙니다.
그리고 사흘 누적 부분은 아직 검증되지 않았습니다 ([`../../docs/PERSISTENCE.md`](../../docs/PERSISTENCE.md)).
화면에도 그렇게 적어뒀으니 발표에서 지우지 마십시오.
