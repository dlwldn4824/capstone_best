## 흐름

1. 측정 전 세 가지: 어젯밤 잔 시간 · 커피/에너지드링크 잔 수 · 지금 기분 (삼성화재 앱의 키 · 몸무게 입력 자리)
2. 30초 스캔: 얼굴 메시(MediaPipe) 이마 · 양 볼 평균 RGB → 실시간 맥파 · 심박 표시
3. 브라우저에서 분석 (`vitals.js`) → 숫자만 서버로 (`/api/c/scan`)
4. 결과: 종합 점수 · 항목별 점수 · 지표 6개 · 평소 대비 · 추천 최대 3개
5. 스트레스가 높으면 **1분 호흡**(4초 들숨 · 6초 날숨 × 6) → 다시 재기 → 전후 비교 카드

## 알고리즘 (`research/src/nesy/vitals.py` = `webapp/static/vitals.js`, 브라우저와 소수점까지 같음)

| 단계 | 방법 |
| --- | --- |
| 맥파 | POS (Wang 2017), rPPG-Toolbox 처리 순서 — 기존 `rppg.pos_v2` |
| 심박 | 맥파 주기도 최고점 (0.6–3.3 Hz) · SNR = 1 · 2차 고조파 ±6 bpm 에너지 비 |
| 박동 | **내 심박 ±0.4 Hz 로 좁힌 맥파**(1차 버터워스 두 번) 극대점 + 3점 포물선 보간 + 최소 간격 0.5주기 |
| 간격 정리 | 0.33–1.5초 · 전체 중앙값 ±30% · 이웃 5개 중앙값 ±20% 밖은 버림 |
| HRV | RMSSD(인접 두 간격이 모두 살아 있을 때만) · SDNN · pNN50 |
| 스트레스 | Baevsky SI = AMo / (2·Mo·MxDMn), 50 ms 구간 → 0–100 = SI 50–1000 의 로그 눈금. 30 / 60 / 80 으로 편안 · 보통 · 높음 · 매우 높음 |
| 리듬 | 신호 좋음(SNR ≥ 3 dB) + 박동 80% 이상 잡힘일 때만, 인접 간격 차가 평균의 20%를 넘는 비율 > 30% 면 '불규칙'. 이웃 정리 **전** 간격으로 본다 (정리하면 불규칙이 지워진다) |
| 호흡 | 맥파 기저선(RIIV) · 박동 높이(RIAV) · 박동 간격(RIFV)의 0.1–0.5 Hz 최고점 → 품질 0.3 이상끼리 4회/분 안에서 맞으면 평균 (Karlen 2013) |
| 신뢰도 | 신호: SNR ≥ 3 좋음 · ≥ 0 보통 · 그 아래 약함. HRV 는 박동 70% 이상 남아야 보고 |
| 종합 점수 | 스트레스(100 − 지수) 35% + HRV(ln RMSSD 10→80 ms) 20% + 심박(55–85 bpm) 15% + 생활 30% (수면 7–9시간 · 카페인 0–1잔 · 기분). 빠진 항목은 빼고 다시 나눔. **호흡은 0%** |
| 평소 | 최근 14일, 신호 약함 · 호흡 뒤 측정 제외, 3번 이상이면 중앙값 |

## 검증 — MCD-rPPG 100명, 운동 전 · 후 영상, 30초 창 1,001개, 손끝 PPG 에 같은 계산

> 이 검증(심박 0.33 bpm 등)은 `/check` 의 `vitals.js`(= `research/src/nesy/vitals.py`) 엔진에만 해당한다. `/face`(`webapp/face/src/pipeline/`)는 다른 엔진이라 이 수치를 쓰지 않는다 — [FACE_DESIGN.md](FACE_DESIGN.md).

| 지표 | 신호 좋은 창 (129) | 전체 보고된 창 |
| --- | --- | --- |
| 심박 | 오차 0.33 bpm · ρ 0.99 | 3.3 bpm (1,001창) |
| RMSSD | 오차 중앙값 7.5 ms · ρ 0.56 | 10.1 ms · ρ 0.59 (418창, 42%) |
| SDNN | 6.1 ms · ρ 0.73 | 7.1 ms · ρ 0.71 |
| 스트레스 0–100 | 13.9 · ρ 0.72 | 13.7 · ρ 0.71, 같은 구간 58% |
| 호흡 | ρ 0.12 (손끝 PPG 에서 뽑은 호흡과) | → **참고값, 점수 제외** |
| 불규칙 오탐 | 0 / 129 (건강한 사람) | |

- 넓은 대역(0.6–3.3 Hz) 그대로 박동을 찾으면 박동 시각이 ±40 ms 흔들려 RMSSD 가 83 ms(손끝 31 ms)로 부풀었다.
  내 심박 ±0.4 Hz 로 좁히자 32 ms 로 맞았다 (`research/scripts/27_vitals.py` 실험).
- 운동 전후: 손끝 PPG 로도 심박이 오른 사람이 62%뿐(촬영 사이 회복). 얼굴도 60%로 같은 수준.
- 진짜 부정맥 데이터로는 확인하지 않았다 — '불규칙'은 다시 재기 · 반복되면 보건실 안내로만 쓴다.

## 추천 규칙 (`webapp/check.py` `tips`, 진단 · 처방 없음)

신호 약함 → 다시 재기 · 불규칙 → 다시 재기, 반복되면 보건실/병원 심전도 · 심박 > 100 → 3분 쉬고 다시 ·
스트레스 ≥ 60 → 1분 호흡 · 카페인 2잔+ & 심박 높음 → 오늘 커피 그만 · 수면 < 6시간 → 25/5 공부 단위 ·
HRV < 평소 70% → 일찍 자기 · 기분 ≤ 2 → 학생상담센터 · 23시 이후 긴장 → 잠자리 준비 · 다 괜찮으면 어려운 과목부터.

## 인증 그룹 · 오늘의 공부 모드 (v0.4)

| 기능 | 규칙 | 코드 |
| --- | --- | --- |
| 그룹 만들기 | 이름 1–20자 · 인증 시간대 1시간 이상 · 최대 10명 · 6자리 초대 코드(0 O 1 I 제외) | `check.create_group` |
| 참여 · 나가기 | 한 사람 최대 5개 그룹, 그룹별로 나가기. 방장이 나가면 가장 먼저 들어온 사람에게, 마지막 사람이 나가면 그룹 삭제 | `join_group` · `leave_group` |
| 인증 | 측정 한 번으로 지금 시간대가 열린 내 그룹 전부에 인증 (그룹마다 하루 한 번). 맥박이 잡혀야(신호 보통 이상) 인증, 호흡 뒤 측정은 안 씀. 결과엔 그룹별로 완료 · ○시부터 · 끝남 | `try_checkin` |
| 그룹에 보이는 것 | 이름 · 인증 시각 · 연속 일수 · 방장 여부만. 점수 · 심박 · 얼굴 없음 (테스트로 고정) | `group_state` |
| 공부 모드 | 23시 이후 마무리 · 점수 < 55 / 긴장 ≥ 70 / 잠 < 5시간 → 가볍게 복습 15+5분 · 점수 ≥ 75 & 긴장 < 50 → 깊게 집중 50+10분 · 그 외 나눠서 집중 25+5분 | `study_mode` |
| 공부 타이머 | 공부 모드의 집중 · 휴식 분으로 반복, 전환 때 진동, 일시정지 | `check.html` |

사람 구분: 브라우저마다 무작위 아이디(`localStorage vity.mid`)와 이름. 측정 · 키 · 몸무게 · 동의도 이 아이디별로 따로 저장되고,
남의 측정은 열 수 없다. 로그인이 없으므로 아이디를 아는 사람은 그 기록을 볼 수 있다 → 실서비스에서는 계정 또는 기기 내 저장으로.
