# PMData — "어제 술을 마셔서 그런 건데요" 를 실제 기록으로 잰다

[`MISHRA.md`](MISHRA.md) 에서 설명 계층은 일하지 않았다. 걸음·수면만으로는 이탈일의 16% 만
설명됐다. README 가 말한 '평소와 다른 날' 의 원인 — 음주, 스트레스 — 이 기록되지 않았기 때문이다.
PMData 에는 **음주 여부와 스트레스가 매일** 적혀 있다.

| | |
| --- | --- |
| 출처 | Thambawita et al., MMSys 2020 · Simula · **CC BY 4.0** |
| 위치 | [`pmdata.zip`](https://datasets.simula.no/downloads/pmdata.zip) (공개, 1.4 GB, 대부분 음식 사진) |
| 사람 | 노르웨이 16명 · 2019-11 ~ 2020-03 · Fitbit Versa 2 |
| 맥락 | 음주 여부(매일, 471일 '예') · 웰니스 설문(스트레스·수면의 질 등 1~5) · 부상 |
| **없는 것** | 감염 라벨. 여기서는 헛경보만 잰다 |

```bash
unzip pmdata.zip -x '*/food-images/*' -d data/raw/pmdata
python scripts/21_pmdata_context.py
```

## 로더 (`src/nesy/pmdata.py`) — 감사에서 확인한 함정

| 함정 | 처리 |
| --- | --- |
| `reporting.csv` 날짜가 **일/월/년** | 06/11/2019 = 11월 6일. 월/일로 읽으면 6월이 된다 |
| 웰니스 점수는 **5 가 좋은 쪽** | 스트레스가 기분(ρ=0.41)·수면의 질(ρ=0.30)과 양의 상관 → `stress <= 2` 가 '스트레스 받음' |
| 심박 JSON 이 1인당 120 MB | `json.load` 대신 정규식으로 읽는다 (1인 약 2초) |
| 설문은 UTC, Fitbit 은 현지 시각 | 설문을 Europe/Oslo 로 바꾼다 |
| 음주는 그날 저녁 → 그날 밤 | 밤을 깨어난 날에 붙였으므로 **전날 음주**가 그날 밤을 설명한다 |
| 밤 심박 | 수면 단계 구간(light/deep/rem) 안의 심박만. 시계 시각으로 자르지 않는다 |

## 결과 (2026-10-03, 15명 · 유효일 1,498)

음주 기록률 61%, 스트레스 기록률 79%. 기록 없는 날은 '아니오' 로 셌다 (보수적).

### 1. 그 원인이 있던 밤, 밤 심박이 오르는가 (사람별 짝 비교, Wilcoxon)

| 원인 | 사람 | 밤 | 중앙 차이 | 오른 사람 | p |
| --- | --- | --- | --- | --- | --- |
| **전날 음주** | 13 | 344 | **+2.6 bpm** | **12/13** | **<0.001** |
| **수면 부족** | 15 | 430 | +0.9 bpm | **14/15** | **<0.001** |
| 전날 고강도 운동 | 15 | 1,065 | +0.4 bpm | 10/15 | 0.15 |
| 스트레스 (설문) | 14 | 355 | +0.2 bpm | 8/14 | 0.67 |

**음주는 이 프로젝트에서 가장 강한 '설명' 이다.** 실험실 스트레스 반응(Hongn +7.7 bpm)보다는
작지만, 13명 중 12명에서 같은 방향이다. 반대로 **설문 스트레스와 운동은 밤 심박을 움직이지 않는다.**
규칙에 넣을 근거가 없다 (스트레스는 피부전도로 보는 쪽이 맞다 — 결과 4·7번).

### 2. 설명 원인을 더할수록

| 조건 | 이탈일 중 설명됨 | 경보/인·월 K=1 | K=2 | K=3 |
| --- | --- | --- | --- | --- |
| raw | 0% | 1.73 | 0.55 | 0.16 |
| 센서 (운동·수면) | 40% | 1.28 | 0.28 | 0.08 |
| + 음주 | 55% | 1.02 | 0.20 | 0.06 |
| + 스트레스 | 60% | 0.98 | 0.16 | 0.04 |
| 맥락만 (음주·스트레스) | 36% | 1.24 | 0.35 | 0.12 |
| **무작위 (같은 개수)** | 60% | 0.98 | **0.12** | **0.02** |

이탈일 166일 → 설명 99일 (운동 46 · 음주 24 · 수면 21 · 스트레스 8) / 미설명 67일.

**정직하게 읽으면:** 경보가 줄어드는 것은 **같은 개수를 무작위로 걷어내도 그만큼 줄어든다.**
감염 라벨이 없는 데이터에서 경보 감소만으로는 설명 계층의 가치를 증명할 수 없다.

이 데이터가 증명하는 것은 두 가지다.
1. **설명이 맞는 설명이다.** 음주·수면 부족은 실제로 밤 심박을 올린다 (1번 표).
   규칙이 '아무 날이나' 닫는 것이 아니라 원인이 있는 날을 닫는다.
2. **기록하면 설명된다.** 걸음·수면만으로 40% → 음주를 더하면 55%. Mishra(16%)와의 차이는
   맥락 기록의 차이다.

그리고 증명하지 못하는 것: "설명된 날을 걷어내도 **감염은 놓치지 않는다**" — 이것은 감염 라벨이 있는
Mishra 로만 볼 수 있고, 거기서는 아직 차이가 없다. 두 데이터를 합쳐야 한 문장이 된다.
