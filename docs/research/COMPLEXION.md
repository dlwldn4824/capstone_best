# 안색이 무엇을 가리키는가 — 확인할 방법

안색을 앱에 넣기 전에 답해야 하는 것은 하나다. **얼굴 붉은 기(a\*)가 무엇을 담고 있는가.**
지금까지는 "운동 전후"로만 물었고, 답은 계속 "모른다"였다. 다르게 물을 방법을 적어 둔다.

## 1. 지금까지 안 것

| 언제 | 무엇을 쟀나 | 결과 |
| --- | --- | --- |
| `24_mcd_analysis.py` | 원 a\* (얼굴 평균 RGB → Lab), 100명 | 운동 후 상승 52% · p = 0.71 |
| `29_complexion_corrected.py` | 보정 a\* (볼 − 이마), 19명 | 운동 후 상승 47% · p = 1.00 |

보정의 효과는 분명하다. 같은 영상 안 20초 구간끼리의 흔들림이 **1.208 → 0.360 (3.4배)** 줄었다.
같은 프레임 안에서 두 영역을 빼면 기기가 입히는 색 변환과 그 순간의 조명 · 화이트밸런스가 상쇄되기 때문이다.
문서에 적힌 1.57 → 0.63보다 큰 개선이다.

그런데도 운동 전후는 안 갈린다. **잡음 문제가 아니라 운동 전후가 안색에 안 나타나는 것이다.**

같은 날 MCD-rPPG 가 같이 주는 건강 지표 11개와도 대 봤다 (20명 · 안정 영상 · Spearman).

| | 원 a\* | 보정 a\* | 밝기 L\* |
| --- | --- | --- | --- |
| 헤모글로빈 | ρ = −0.08 | ρ = −0.25 (p = 0.28) | ρ = −0.23 |
| 당화혈색소 · 콜레스테롤 · 혈압 · BMI · 나이 · 스트레스 | 모두 \|ρ\| < 0.3, p > 0.2 | | |
| 산소포화도 | | ρ = +0.42 (p = 0.05) | |
| 체온 | | | ρ = +0.55 (p = 0.01) |

**살아남는 것은 없다.** 비교를 33번 했으니 p = 0.05 짜리 하나쯤은 그냥 나온다.
체온은 36.3–36.8, 산소포화도는 94–99 — 범위가 좁아 애초에 못 쓴다.
다만 **20명은 너무 적다.** ρ = −0.25 는 n = 20 에서 보일 수 없는 크기다. 이게 2번의 출발점이다.

## 2. 문헌이 말하는 것

| 무엇 | a\* 가 움직이나 | 근거 |
| --- | --- | --- |
| 헤모글로빈 · 빈혈 | **입술 · 결막 · 손바닥에서는 그렇다. 얼굴 피부는 확인된 바 없다** | Horibata 2025 (J Gen Fam Med) — 입술과 결막만 빈혈군에서 유의, 92명 중 빈혈 25명 |
| 수면 부족 | **아니다. 노란 기(b\*)가 오른다** | Jang 2023 (J Clin Med) 28명/10명 — 노란기 상승, 붉은기 변화 없음 · Holding 2019 (J Sleep Res) 181명 — 분광측색으로 아무 변화 없음 |
| 음주 | 안면홍조. 효과가 크고 아시아인에게 흔하다 (ALDH2) | 상식 수준. 쓸 거면 출처를 따로 확인할 것 |

읽을 점 둘.

- **얼굴 피부로 빈혈을 본 연구는 못 찾았다.** 되는 자리는 전부 점막(입술 · 결막)이거나 손바닥이다.
  얼굴은 빈 자리다 — 기회이기도 하고, 아무도 안 한 이유가 있을 수도 있다.
- **수면 부족을 보려면 a\* 가 아니라 b\* 를 봐야 한다.** 지금 우리는 b\* 를 아예 안 보고 있다.

공개 데이터는 기대가 낮다. 얼굴 영상과 안색 관련 라벨이 같이 있는 공개 데이터는 사실상 없다.
DIF(음주 얼굴 영상)는 라벨이 '보기에 취한' 웹 영상이라 쓸 수 없고,
얼굴 영상 → 총 헤모글로빈 279명 연구(PMC12384772)는 공개 여부가 불명이라 저자 문의가 유일한 길이다.

## 3. 할 수 있는 실험

두 질문을 구분해야 한다. 섞으면 답이 안 나온다.

- **타당성** — 얼굴 붉은 기가 생리적으로 무엇을 담고 있나. 사람끼리 비교해서 본다. → 실험 A
- **유용성** — 그게 이 앱 구조(내 평소 대비)에서 쓸모가 있나. 같은 사람 안에서 본다. → 실험 B

타당성이 있어도 유용성은 없을 수 있다. 헤모글로빈은 사람끼리는 갈리지만 **내 안에서는 몇 달째 그대로**라,
상관이 나와도 앱의 "오늘 평소와 다르다"에는 못 쓴다. 그래서 B 가 실제로 더 중요하다.

### A. 가진 데이터를 20명 → 600명으로 (반나절, 돈 0, 사람 손 안 감)

```bash
python research/scripts/23_mcd_extract.py --n 600
python3.13 research/scripts/29_complexion_corrected.py
```

- 영상은 받는 즉시 지우므로 디스크는 `traces/` 가 13MB(20명) → 약 400MB 로 느는 게 전부다.
- 시간은 100명에 25분이니 600명이면 2.5시간. 밤에 걸어 두면 된다.
- n = 600 이면 지금 ρ = −0.25 · p = 0.28 인 헤모글로빈이 **같은 ρ 에서 p < 10⁻⁹** 가 된다.
  **있으면 보이고, 없으면 없다고 말할 수 있다.** 지금은 둘 다 못 한다.
- 같이 고칠 것 둘:
  - **b\* (노란 기)와 L\* (밝기)도 같이 본다.** 문헌이 수면은 b\* 라고 한다. `roi` 가 이미 npz 에 있으니 분석만 늘리면 된다.
  - **피부톤을 공변량으로 넣는다.** 사람끼리 비교하면 멜라닌이 a\* 를 끌고 간다. L\* 이나 ITA° 로 층화하거나 편상관을 쓴다.
- 쓸 만한 라벨: 헤모글로빈(9.3–17.3, 20명 중 빈혈 6명), 당화혈색소(3.75–11.23), 콜레스테롤, 혈압.
  체온과 산소포화도는 범위가 좁아 뺀다.

### B. 직접 모으기 — '내 평소 대비'를 검증하는 유일한 길 (2주)

앱이 이미 재고 저장한다. 추가 개발은 보정 a\* 계산과 저장뿐이다.

- 팀원 n명 × 하루 2회(아침 · 자기 전) × 14일 = 사람당 28회. 기준선은 5회부터 서니 충분하다.
- 같이 적는 것: 수면 시간, 음주, 운동, 카페인, 실내/실외, 화장.
- 답할 수 있는 질문, 순서대로:

  1. **같은 사람의 날짜별 변동이 측정 잡음 0.36보다 큰가.**
     이게 '아니오'면 안색은 거기서 끝이다. 무엇과 연결되는지 물을 필요도 없다. **제일 먼저 답할 것.**
  2. **음주한 날 a\* 가 오르는가.** 기대 효과가 가장 큰 가설이다.
     효과가 크면 5명 × 10회로도 보인다. 안 보이면 다른 것도 안 보인다고 봐도 된다.
  3. **수면 부족엔 b\* 를 본다.** a\* 가 아니다 (Jang 2023).
- 같이 챙길 것: 그레이 카드 한 장. 보정이 실제로 기기 차이를 지우는지 확인하는 유일한 기준이 된다.
  팀원 폰 기종이 다르면 그 자체가 기종 보정 실험이다.
- 한계: 라벨이 자기보고고 n이 작다. 전시에 "팀 자가 실험 n = 5" 라고 그대로 적는다.

### C. 공개 데이터 — 기대 낮음

- DIF (음주 얼굴 영상): 라벨이 '보기에 취한'이라 못 쓴다.
- 얼굴 영상 → 총 헤모글로빈 279명 (PMC12384772): 공개 여부 불명. 저자 문의.
- 결막 · 입술 데이터는 있지만 우리 ROI 가 아니다. **다만 ROI 를 입술로 늘리는 건 생각해 볼 만하다** —
  문헌에서 되는 자리가 거기다. MediaPipe 랜드마크로 입술 영역을 뽑는 건 어렵지 않다.

## 4. 순서

1. **오늘 밤** — `23_mcd_extract.py --n 600` 을 걸어 둔다. 사람 손이 안 가고 비용이 0이다.
2. **내일** — 자가 실험 B 를 시작한다. 질문 1(변동 > 잡음)부터. 2주면 전시에 쓸 숫자가 나온다.
3. **둘 다 '없다'로 나오면** 안색은 재서 기록만 남기고 판정에서 뺀다.
   그건 실패가 아니라 지금 상태가 맞다는 확인이고, 그대로 발표할 수 있는 결과다.

- "안색으로 스트레스 · 피로 · 건강을 본다"
