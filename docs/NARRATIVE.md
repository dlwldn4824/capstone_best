# 발표 서사 — 문제 · 연구 · 서비스 (하드웨어는 +α)

무게중심을 **소프트웨어 연구**에 둔다. 실제로 검증한 것이 그것이고,
하드웨어는 그 결론에서 따라 나오는 확장이다.

```
문제 정의  ──►  우리 접근  ──►  검증한 것  ──►  서비스  ──►  (+α) 하드웨어
   1장          1장           4장           2장          1장
```

---

# 1. 문제 정의

## 1.1 웨어러블은 "평소와 다르다"까지만 말한다

심박이 올랐다는 사실은 알려주지만 **왜** 올랐는지는 말하지 못한다.
계단을 뛰어서인지, 발표 직전이라 긴장해서인지, 몸에 이상이 생겨서인지.

## 1.2 감염과 스트레스는 같은 경로로 수렴한다

병원체 감염과 심리적 스트레스는 매개 인자가 다르지만
**말초 자율신경 반응은 같은 형태로 나타난다.** 심박 상승, 피부전도 상승,
체온 변화. 손목에서 재는 신호로는 원리적으로 구별되지 않는다.

## 1.3 그래서 오탐이 발생한다

상용 알고리즘은 개인 기준선 대비 편차로 판정한다. 그러면 다음 넷을 감염과
구별할 방법이 없다.

| 교란 | 왜 감염처럼 보이는가 |
| --- | --- |
| 격렬한 운동 | 다음 날 아침까지 안정 심박을 올려둔다 |
| 수면 부족 | 부교감 활동이 감소해 변화 방향이 같다 |
| 심리적 스트레스 | 교감 활성화로 심박 상승, HRV 감소 |
| 과도한 음주 | 야간 안정 심박 상승 |

Mishra 2020 은 이 문제를 정량화했다 — **건강 대조군에서도 평균 0.66회/인·월
경보가 발생한다.**

## 1.4 문제를 다시 쓰면

> 감염을 직접 찾는 것이 아니라, **설명되는 변화를 걸러내는 것**이 문제다.

---

# 2. 우리 접근

## 2.1 구별하지 않고 소거한다

```
이 사람의 평소와 다른가?
        ↓  다르다
운동으로 설명되나?      (가속도)
스트레스로 설명되나?    (피부전도)
수면·음주로 설명되나?   (사용자 입력)
        ↓  전부 아니다
   설명되지 않는 변화
        ↓
   며칠 지속되는가?
        ↓
      알림
```

## 2.2 이 구조의 핵심

**분류기는 기권할 수 없다.** 학습한 것 중 하나를 반드시 골라야 한다.
우리 구조는 **"모른다"고 답할 수 있다.** 실제로 몸에 이상이 생기면 그것은
우리가 규칙을 만들어 둔 맥락이 아니므로, 모른다고 답하는 것이 정답이다.

# 3. 검증한 것

공개 데이터 두 개로 직접 확인했다. **실험실 하나, 실환경 하나.**

| | Hongn 2025 | Nurse Stress 2022 |
| --- | --- | --- |
| 환경 | 실험실, 통제된 프로토콜 | 실제 병원 근무 |
| 대상 | 건강 성인 34명 | 간호사 15명 |
| 규모 | 1,251 윈도 | **148,929 윈도 / 1,241시간** |
| 라벨 | 프로토콜 구간 | 교대 후 설문 사건 |

## 3.1 재현 — 그리고 논문 수치를 그대로 믿으면 안 된다

원 논문(93/91/84%)을 재현했다. 그런데 **피험자를 분리하면 Macro F1 이 0.09
떨어진다.**

| 분할 | Macro F1 |
| --- | --- |
| 논문과 같은 방식 (피험자 무분리) | 0.923 |
| LOSO | 0.832 |
| **GroupKFold (우리 보고값)** | **0.809** |

60초 윈도를 30초 간격으로 겹쳐 뽑으므로 인접 윈도가 거의 같은 신호를 공유한다.
여기에 같은 사람이 학습·평가 양쪽에 들어가면 성능이 부풀려진다.

## 3.2 대표 질문을 다시 잡았다

오분류 253건이 어디서 나는지 세어 보니,

| | 건수 | 비중 |
| --- | --- | --- |
| **휴식 ↔ 스트레스** | 214 | **85%** |
| 스트레스 ↔ 운동 | 24 | 9% |
| 휴식 ↔ 운동 | 15 | 6% |

**운동은 가속도만 넣으면 거의 완벽히 갈린다.** 진짜 난제는 **가만히 있을 때
평상과 각성을 구분하는 것**이고, 이는 "개인 평소에서 벗어났는가" 와 같은 문제다.

## 3.3 왜 개인 기준이 필요한가 — 숫자로

| | |
| --- | --- |
| 사람마다 다른 평소 심박 | 53 ~ 101 bpm (SD **10.0**) |
| 한 사람이 스트레스 받을 때 | **+7.7 bpm** (34명 중 **30명**) |

**반응은 일관되게 존재하는데 개인차가 그보다 크다.** 피부전도는 41배다.
누구의 데이터인지 모르는 모델은 이 신호를 쓸 수 없다.

## 3.4 실험실 규칙은 실환경으로 **부분만** 이식된다

같은 규칙을 실제 병원 근무 1,241시간에 적용했다.

| 채널 | 실험실 | 실환경 | |
| --- | --- | --- | --- |
| **피부전도 (EDA)** | 상승 | **+1.72, 13/15명, p=0.001** | ✅ |
| **SCR 빈도** | 상승 | **+4.0, 12/15명, p=0.007** | ✅ |
| 심박 | +7.7 (30/34) | +2.0 (11/15), p=0.169 | △ |
| **HRV (RMSSD)** | 20/36 (우연) | **7/15 (우연), p=0.978** | ❌ |

**교과서적 "스트레스 → HRV 감소"가 두 데이터 모두에서 성립하지 않는다.**
36명 중 20명, 15명 중 7명 — 두 번 다 우연 수준이다.

**그런데 왜 안 되는지는 3.7 에서 답한다.**

## 3.5 활동량 임계도 이식되지 않는다

실험실에서 5개 fold 전부 동일하게 선택된 **0.020 g** 가,
실환경에서는 **윈도의 73.6%** 에서 참이 된다.

**병동을 계속 걷는 간호사에게 "움직이지 않음" 조건은 발화하지 않는다.**
고정식 자전거에서 얻은 값이 보행 환경으로 옮겨가지 않는다.

## 3.6 결정적 실험 — 모르는 것을 모른다고 하는가

운동 규칙을 **통째로 제거하고** 운동 구간을 입력했다.
비교군도 **운동을 한 번도 학습하지 않은** 분류기로 맞췄다.

| 운동을 모르는 상태에서 운동 구간을 보고 | |
| --- | --- |
| 분류기 | **96.2% 를 "스트레스"라고 단정** |
| 우리 구조 | **95.0% 를 "설명 안 됨"** |

분류기는 기권 선택지가 없어 아는 것 중 하나로 밀어 넣는다.
**이것이 규칙을 두는 이유다.**

## 3.7 세 번째 데이터로 원인을 밝혔다

두 데이터 모두 **손목 PPG** 로만 쟀으므로 위 결과가
**(a) 생리적 사실** 인지 **(b) 손목의 측정 한계** 인지 가를 수 없었다.

WESAD 는 **같은 사람 같은 시각**에 가슴 ECG(700 Hz)와 손목 PPG(64 Hz)를
동시에 기록한다. 15명 / 877 윈도 / baseline vs TSST.
**두 신호에 같은 HRV 함수를 적용**해 비교했다.

| | REST → STRESS | 감소한 사람 |
| --- | --- | --- |
| **가슴 ECG** RMSSD | 48.6 → 32.0 (**−27%**) | **10 / 15** |
| **손목 PPG** RMSSD | 154.0 → 133.2 (**방향 반대**) | 7 / 15 |

### 결정적 대조 — 같은 윈도에서 HR 은?

| | 차이 | 상승 |
| --- | --- | --- |
| 가슴 ECG | +21.2 bpm | **15 / 15** (p=0.0001) |
| 손목 PPG | +24.4 bpm | **15 / 15** (p=0.0001) |

**심박수는 손목으로도 완벽히 잡힌다.** 신호가 나쁜 것이 아니라
**HRV 라는 지표가 손목에서 못 쓰이는 것**이다.

### 메커니즘

| 지표 | ECG | PPG | 상관 |
| --- | --- | --- | --- |
| 평균 박동 간격 | 0.8 s | 0.7 s | **0.903** |
| RMSSD | **38.0** | **138.1** | 0.529 |

평균은 잘 맞는데 **박동 간 변이만 3.6배 부풀려진다.**
PPG 맥파는 정점이 완만해 검출 시각이 수 밀리초씩 흔들리는데,
RMSSD 는 연속한 간격의 *차이* 를 재므로 그 지터가 그대로 들어온다.
평균은 지터가 상쇄되어 살아남는다. 그래서 HR 은 되고 HRV 는 안 된다.

> **HRV 는 스트레스에 반응한다. 다만 손목 PPG 로는 잴 수 없다.**

이것이 5장 하드웨어 논거의 직접 근거다.

---

## 3.8 정리 — 다섯 가지 발견

1. 실험실 규칙은 실환경으로 **부분만** 이식된다 (EDA ✅ / HR △ / HRV ❌)
2. **HRV 는 반응하지만 손목 PPG 로는 잴 수 없다** — 가슴 ECG 와 동시 측정으로 확인.
   HR 은 손목으로도 15/15명 잡히므로 신호가 아니라 **지표의 문제**다
3. 개인 기준은 **같은 착용 구간** 단위여야 한다 (세션 간 드리프트가 신호의 2.5~14배)
4. 이탈은 **방향을 반영**해야 한다 (각성 방향만 더하면 두 환경 모두 개선)
5. 분류기는 기권 못 하지만 **규칙 구조는 한다**

# 4. 서비스

## 4.1 문제 정의로 되돌아간다

1장에서 이렇게 적었다.

> **사용자 입력이 없는 기기**는 운동·수면부족·스트레스·음주를 감염과 구별할
> 방법이 없다.

**그러면 입력을 받는 서비스를 만들면 된다.** 그리고 그 입력이 우리 시스템이
필요로 하는 맥락 정보 그 자체다.

## 4.2 하루 한 번, 30초

```
새벽    잘 때 잰다            ← 움직임이 없어 교란이 사라진다
아침    "어젯밤 평소와 다른 패턴이 있었어요"
        "혹시 어제 이런 게 있었나요?"
          □ 운동  □ 늦게까지 일  □ 음주  □ 스트레스
             ↓
        체크함        →  "그래서였군요"          (종결)
        아무것도 없음  →  미해결로 누적
             ↓
        3일 연속 미해결 → "컨디션 확인해 보시는 게 좋겠어요"
```

**이 화면이 곧 제품이자 데이터 수집기다.** 사용자는 자기 상태를 설명받고,
시스템은 맥락 라벨을 얻는다.

## 4.3 왜 밤에 재는가

우리 실측이 시킨 설계다.

- 실환경에서는 활동량이 상시 높아 **깨어 있는 시간의 신호는 활동에 압도된다**
- 야간에는 움직임·실온·자세가 모두 안정된다
- 선행연구(Mishra, Quer)도 **야간 안정 심박**을 쓴다

## 4.4 넘지 않는 선

```
❌ "감염이 의심됩니다"          진단이다. 의료기기 규제 대상이고 위험하다.
✅ "설명되지 않는 변화가 3일째"  관찰의 보고다.
```

**진단하지 않는다. 설명하지 못한 변화를 알릴 뿐이다.**

## 4.5 시연

| 시연 | 방법 | 화면 |
| --- | --- | --- |
| 운동 | 현장에서 계단 | "운동으로 설명됨" |
| 스트레스 | 현장에서 암산 과제 | "스트레스로 설명됨" |
| **미해결** | 미리 기록한 궤적 재생 | **"3일째 설명되지 않음"** |

**셋을 나란히 보이는 것이 주장 전체다** — 설명되는 것은 걸러내고 남은 것만 알린다.

# 5. (+α) 하드웨어

지금까지의 검증은 **손목 PPG · EDA · 가속도 · 피부온도** 만으로 이뤄졌다.
서비스도 이 구성으로 성립한다. 아래는 **더 하면 좋은 것**이다.

## 5.1 지금 구성으로 충분한 이유

3.4 에서 **피부전도가 실환경으로 이식되는 유일한 채널**임을 확인했다.
그리고 피부전도의 역할은 감염 탐지가 아니라 **스트레스를 소거하는 것**이다.
소거법 구조에서는 그것으로 족하다.

## 5.2 자체 제작 시 실제 난제

센서 선정이 아니다.

| 난제 | |
| --- | --- |
| **야간 배터리** | 8시간 이상. 샘플링을 낮추고 로컬 저장 후 아침 전송 |
| **전극 접촉** | 실측에서 세션 간 EDA 바닥값이 15배까지 튀었다. 접촉이 나쁘면 데이터 전체가 무의미해진다 |
| **착용감** | 자다가 빼면 끝이다 |

검증은 **기존 기기와 같은 팔에 2~3시간 동시 착용**해 상관을 보는 것으로 충분하다.

## 5.3 더 하면 좋은 것

| 우선 | 항목 | 비고 |
| --- | --- | --- |
| 1 | 호흡수 | PPG 진폭변조에서 추출. 센서 추가 없음 |
| 2 | 심부 체온 | **야간 피부 온도로 상당 부분 대체 가능** (Oura 가 그렇게 한다) |
| 3 | 땀 코르티솔 | Kaya 2026 이 효과를 보였으나(77.8→94.4%) 소모품·교정 문제 |

**심부 체온 자체 제작은 권하지 않는다.** 만드는 것보다 검증이 어렵다 —
직장 온도나 삼킴형 캡슐 같은 기준값이 필요하고, 그것만으로 별도 연구가 된다.

# 부록 — 평가를 어떻게 할 것인가

정확도를 쓰면 안 된다. 감염이 몇 건이고 정상이 수천 일이면 "전부 정상"이
99.9% 다.

**Mishra 의 지표를 그대로 쓴다.**

| 지표 | Mishra | 우리가 겨냥할 것 |
| --- | --- | --- |
| 증상 전 탐지율 | 24명 중 15명 (62.5%) | 사건이 적어 통계가 안 나온다 |
| **오경보율** | **0.66회 / 인·월** | **← 여기에 검정력이 있다** |

```
맥락 설명 없이 :  오경보 X회 / 인·월
맥락 설명 켜고 :  오경보 Y회 / 인·월     Y < X 인가?
                  (탐지율은 유지되는가?)
```

조용한 사람·날이 수천 건이므로 **오경보 쪽은 통계가 나온다.**
그리고 그것이 우리 기여의 실체다 — 설명되는 변화를 걸러낸다.
